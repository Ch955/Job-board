How do I get a token?
  1. Open GitHub → new fine-grained token.
  2. Name it Job Radar, expiration 1 year.
  3. Repository access: Only select repositories → your Job-board repo.
  4. Permissions → Repository → Contents: Read and write.
  5. Generate token, copy it, paste it here.

Your passphrase encrypts your statuses. It never leaves this device, and GitHub can't read the file. Use the same passphrase on every device.
